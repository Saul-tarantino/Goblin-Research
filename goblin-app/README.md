# 哥布林探测器 · Goblin Detector

Dr. Jin 出品的恶搞小工具：输入姓名（可选上传照片），即可判定对方是不是哥布林。

> ⚠️ 仅供娱乐，检测结果不构成学术结论。

## 打开方式

直接用浏览器打开本目录下的 `index.html` 即可，无需安装任何依赖，可离线运行。

## 功能

- 输入姓名，按 Enter 或点击"开始检测"。
- 可选上传一张照片，会真实测算绿色像素占比并抬升哥布林指数。
- 生成检测报告：哥布林指数、判定结论、已知样本比对、随机学术结语。
- 点击"🔊 喊出全名"可触发"点名消失反射"动画（98.7% 的哥布林会当场消失）。
