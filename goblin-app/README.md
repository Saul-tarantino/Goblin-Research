# 哥布林探测器 · Goblin Detector

Dr. Jin 出品的恶搞小工具：输入姓名（可选上传照片），即可判定对方是不是哥布林，
并识别出具体是哪一种哥布林、稀有度有多高。

> ⚠️ 仅供娱乐，检测结果不构成学术结论。核心算法已申请专利，恕不公开。

## 打开方式

直接用浏览器打开本目录下的 `index.html` 即可，无需安装任何依赖，可离线运行。

## 功能

- 输入姓名，按 Enter 或点击"开始检测"。
- 可选上传一张照片，用于外观比对（具体算法保密）。
- 综合姓名、外观、检测时刻、拟声词敏感度、天意等多重因素给出哥布林指数。
- 生成详细检测报告：指数、判定结论、参考因素清单、随机学术结语。
- 若判定为哥布林，会给出具体种类与稀有度（共 24 种，分常见 / 稀有 / 史诗 / 传说 / 神话五档）。
- 点击"🔊 喊出全名"可触发"点名消失反射"动画（98.7% 的哥布林会当场消失）。
